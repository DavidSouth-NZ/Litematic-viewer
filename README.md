# Litematic Viewer

View Minecraft schematics in 3D, right in your browser.

**Open it:** https://davidsouth-nz.github.io/Litematic-viewer/

Supports Litematica `.litematic`, Sponge `.schem` and vanilla structure `.nbt` files. Files are read locally in your browser and are never uploaded.

## Features

- Orbit, pan and zoom, or switch to **fly mode** (`F`) to move through walls like spectator mode
- Double-click a block to zoom in on it
- Layer slicing (all / up to / single layer) and X/Z cutaway sliders to open up interiors
- Hover any block to see its block state and coordinates
- Material list with stack and shulker counts; click a block to hide it

## Controls

| Mode | Controls |
| --- | --- |
| Orbit | Drag to rotate · right-drag to pan · scroll to zoom · `[` `]` step layers |
| Fly | Drag to look · `W` `A` `S` `D` move · `Space` up · `Shift` down · scroll for speed · `Esc` to exit |

Blocks are drawn as shaded colored shapes, not Minecraft textures.
